# Estimator & Optuna Study

This directory contains the parameterized **Estimator** flow and an **Optuna-driven hyperparameter study** for exploring fast timing estimation trade-offs in OpenROAD.

---

## 1. Overview

The **Estimator** runs fast physical design exploration using `:fast_estimator_executable` (wrapped by `orfs_run_executable`):
1. Loads the synthesis checkpoint (`1_synth.odb`, `1_synth.sdc`).
2. Runs basic floorplanning and pin placement.
3. Optionally executes global placement with parameterized density and timing/routability flags.
4. Optionally executes global routing with parameterized congestion iterations.
5. Measures slack on target timing paths.

The **Optuna Study** performs multi-objective hyperparameter optimization on `estimator.tcl` to discover configurations that maximize timing slack correlation with ground truth routing while minimizing runtime.

## 3. Running the Optuna Study

The Optuna study binary runs trials exploring different placement and routing parameters for `fast_estimator_executable` and compares the estimated path slacks against `ground_truth.json`.

### Run via Bazel:
```bash
bazel run //test/estimation_ladder:optuna_study
```

### What Happens During the Study:
1. Bazel builds the prerequisite synthesis checkpoint (`:multiplier_asap7_synth`), global route checkpoint (`:multiplier_asap7_grt`), ground-truth extracted paths (`ground_truth.json`), and the standalone `:fast_estimator_executable`.
2. Optuna executes multiple trials sampling parameters from the defined search space.
3. For each trial, `fast_estimator_executable` is executed with trial environment variables and output JSON slacks are compared with ground truth using Pearson correlation ($r$).
4. Upon completion, the Pareto-optimal trials are printed to standard output and written to `test/estimation_ladder/pareto_front.csv`.

---

## 4. Hyperparameter Search Space

The search space in `optuna_study.py` includes:

| Parameter | Type / Range | Description |
| --- | --- | --- |
| `run_place` | Categorical `[0, 1]` | Whether to run global placement. |
| `place_density` | Float `[0.4, 0.9]` | Target placement density during global placement. |
| `place_timing` | Categorical `[0, 1]` | Enable/disable timing-driven placement. |
| `place_routability` | Categorical `[0, 1]` | Enable/disable routability-driven placement. |
| `run_grt` | Categorical `[0, 1]` | Whether to run global routing estimation (requires `run_place=1`). |
| `grt_iterations` | Int `[0, 5]` | Maximum congestion iterations for global routing. |
